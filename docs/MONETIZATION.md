# Free beta and optional support

VOCA's prebuilt beta and corresponding source are free. All local features are included; no checkout, licence key or donation is needed. Cloud API usage remains separately billed by the user's provider.

Optional donations may support development, future signing/notarization and testing. The public support page is [InstinctEx on Ko-fi](https://ko-fi.com/instinctex), configured in `donationUrl` in `config.js`. The website links directly to Ko-fi; no payment data is collected by VOCA. Downloads and every local feature remain free.

This replaces the earlier €5 prebuilt proposal. Existing source archives preserve their historical documentation for exact source correspondence; current distribution terms are free under GPLv3. Retain original notices and matching source with every binary.
